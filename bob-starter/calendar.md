# Bob Calendar

## Config
preferred_calendar: Work
reminder_default_time: 09:00

## Work Defaults
daily_hours: 8
work_days: Mon–Fri

## Standing Weekly Blocks
Recurring commitments that reduce available hours every week.
Remove or comment out when they end.

# Example:
# - Mon: Team standup (30min)
# - Tue: Departmental meeting (2h)

## Upcoming Events
One-off events that consume work time. Bob reads these during briefings.
Format: - YYYY-MM-DD: Description (duration or "no work")
For multi-day: - YYYY-MM-DD to YYYY-MM-DD: Description (no work)
Clean out past events periodically.

# Example:
# - 2026-05-20: IRB committee meeting (2h)
# - 2026-06-12 to 2026-06-15: Annual conference (no work)

## Horizon Notes
Flagged during weekly/monthly planning conversations.
Things to keep on the radar. Remove when no longer relevant.

# Example:
# - Fall 2026: Teaching load picks up — review weekly commitments in August
# - 2026-08-15: Target submission date for [paper]
